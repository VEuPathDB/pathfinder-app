# What was decided

A colocation field nobody states takes the default the site's span form starts on: both
regions exact, every offset 0, every direction `+` (veupathdb-py WDK-STEP-011). Those are
the `ColocationParams` field defaults, so the operator card, FRAME's `set_structure`, the
edit tools and the web editor (which parses the generated schema's defaults) all read one
default. A COLOCATE node of the spec's structure that states no `colocationParams` takes all
of them (`StructureNode`), so a thread saved before the plan carried a colocation loads and
continues.

# Rejected

- **A constant for the operator card beside the model defaults.** The same words built two
  regions, and so two counts, depending on the path that stated them.
- **Refusing a stored COLOCATE node without parameters.** Every thread that held a span
  logic step would end with "This conversation cannot be continued", although the site's
  defaults state what such a node meant.
