# PathFinder mapping rules

The invariants PathFinder holds so that its own types and layers keep meaning what WDK's
mean. Every rule here is `CONTRACT`: none is a fact about WDK. The WDK facts themselves,
and the rules that assert them, are the client library's bundle at
`veupathdb-py: docs/knowledge/wdk/rules/`.
