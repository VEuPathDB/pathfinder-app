PathFinder API
==============

.. rst-class:: lead

   An open-source tool-calling LLM agent for constructing
   **VEuPathDB search strategies** via natural language.

   :gutter: 3

   .. grid-item-card:: Chat & Agent

      Unified agent that researches, plans, and builds strategy graphs
      in a single conversation.

   .. grid-item-card:: Evaluation & Analysis

      Backend evaluation engine for the scored comparison and the control

   .. grid-item-card:: Gene Sets
      :link: api/gene_sets

      Gene set capture, import, export and publication to VEuPathDB.
